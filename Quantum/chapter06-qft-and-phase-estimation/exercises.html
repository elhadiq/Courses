C6.Q1 — Definition and basic properties

\((F_N)_{kj}=\omega_N^{jk}/\sqrt N\) with \(\omega_N=e^{2\pi i/N}\). It is unitary, symmetric, and satisfies \(F_N^{4}=I\).

import numpy as np

def qft_matrix(n):
    N = 2 ** n
    j = np.arange(N).reshape(-1, 1)
    k = np.arange(N).reshape(1, -1)
    return np.exp(2j * np.pi * j * k / N) / np.sqrt(N)

def qft_apply(psi):
    psi = np.asarray(psi, dtype=complex).ravel()
    n = int(round(np.log2(len(psi))))
    return qft_matrix(n) @ psi

import numpy as np

H = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)

def _embed1(U, q, n):
    ops = [np.eye(2, dtype=complex)] * n
    ops[q] = U
    out = np.array([[1.0 + 0j]])
    for o in ops:
        out = np.kron(out, o)
    return out

def _cphase(theta, c, t, n):
    N = 2 ** n
    diag = np.ones(N, dtype=complex)
    for x in range(N):
        bits = [(x >> (n - 1 - k)) & 1 for k in range(n)]
        if bits[c] == 1 and bits[t] == 1:
            diag[x] = np.exp(1j * theta)
    return np.diag(diag)

def _swap(a, b, n):
    N = 2 ** n
    P = np.zeros((N, N), dtype=complex)
    for x in range(N):
        bits = [(x >> (n - 1 - k)) & 1 for k in range(n)]
        bits[a], bits[b] = bits[b], bits[a]
        y = 0
        for k in range(n):
            y = (y << 1) | bits[k]
        P[y, x] = 1
    return P

def qft_circuit_matrix(n):
    N = 2 ** n
    U = np.eye(N, dtype=complex)
    for l in range(n):
        U = _embed1(H, l, n) @ U
        for m in range(2, n - l + 1):
            U = _cphase(2 * np.pi / 2 ** m, l + m - 1, l, n) @ U
    for a in range(n // 2):
        U = _swap(a, n - 1 - a, n) @ U
    return U

def gate_count(n):
    return (n, n * (n - 1) // 2)

C6.Q3 — Reading an eigenphase

import numpy as np

def _qft(n):
    N = 2 ** n
    j = np.arange(N).reshape(-1, 1)
    k = np.arange(N).reshape(1, -1)
    return np.exp(2j * np.pi * j * k / N) / np.sqrt(N)

def qpe_state(phi, t):
    N = 2 ** t
    y = np.arange(N)
    pre = np.exp(2j * np.pi * phi * y) / np.sqrt(N)
    return _qft(t).conj().T @ pre

def qpe_probs(phi, t):
    return np.round(np.abs(qpe_state(phi, t)) ** 2, 10)

def qpe_estimate(phi, t):
    return float(int(np.argmax(qpe_probs(phi, t))) / 2 ** t)

C6.Q4 — One bit of phase per shot, and how many bits you really need

import numpy as np

def hadamard_test_p0(phi):
    return round(float(np.cos(np.pi * phi) ** 2), 6)

def qpe_ancillas(n, eps):
    return int(n + int(np.ceil(np.log2(2 + 1 / (2 * eps)))))

def _probs(phi, t):
    N = 2 ** t
    y = np.arange(N)
    d = phi - y / N
    with np.errstate(divide='ignore', invalid='ignore'):
        amp = np.where(np.abs(np.sin(np.pi * d)) < 1e-14, 1.0,
                       np.sin(np.pi * N * d) / (N * np.sin(np.pi * d)))
    return amp ** 2

def success_prob(phi, t):
    N = 2 ** t
    y = np.arange(N)
    d = np.abs((y / N - phi + 0.5) % 1.0 - 0.5)
    pr = _probs(phi, t)
    return round(float(pr[d <= 1 / N + 1e-12].sum()), 6)

Problem 6.1 Symbolic

C6.S1 — The transform itself

Let \(n={@n@}\), \(N=2^{n}\) and \(F_N|j\rangle=\frac{1}{\sqrt N}\sum_k e^{2\pi ijk/N}|k\rangle\).

(a) Give the matrix element \(\langle k|F_N|j\rangle\) for general \(j,k,N\) (use j, k, N).

\(\langle k|F_N|j\rangle=\) your answer

(b) Give the number of controlled-rotation gates in the standard QFT circuit on \(n\) qubits, as a function of n.

gates \(=\) your answer

(c) Evaluate that count for \(n={@n@}\).

value \(=\) your answer

Show the worked solution

(a) Directly from the definition, \(\langle k|F_N|j\rangle=e^{2\pi ijk/N}/\sqrt N\).

(b) Qubit \(\ell\) receives one Hadamard and controlled rotations from every later qubit, giving \(\sum_{\ell=1}^{n}(n-\ell)=\binom{n}{2}=\frac{n(n-1)}{2}\).

(c) For \(n={@n@}\) this is \({@ta3@}\).

Compare the classical FFT at \(\Theta(N\log N)=\Theta(n2^{n})\): the quantum circuit is exponentially smaller, but it transforms amplitudes, which cannot be read out directly. Truncating rotations below \(2\pi/2^{O(\log(n/\varepsilon))}\) yields the approximate QFT with only \(O(n\log(n/\varepsilon))\) gates.

Problem 6.2 Symbolic

C6.S2 — One qubit of phase information

Let \(U|u\rangle=e^{2\pi i\varphi}|u\rangle\). Prepare the control in \(|+\rangle\), apply controlled-\(U\), then a Hadamard on the control, then measure it.

(a) Give \(\Pr[0]\) as a simplified function of phi.

\(\Pr[0]=\) your answer

(b) Give \(\Pr[0]-\Pr[1]\), again as a function of phi.

\(\Pr[0]-\Pr[1]=\) your answer

Show the worked solution

After the controlled operation the control is \(\frac{1}{\sqrt2}(|0\rangle+e^{2\pi i\varphi}|1\rangle)\) and the target is untouched — this is phase kickback. The Hadamard turns it into \(\frac{1+e^{2\pi i\varphi}}{2}|0\rangle+\frac{1-e^{2\pi i\varphi}}{2}|1\rangle\).

(a) \(\Pr[0]=\left|\frac{1+e^{2\pi i\varphi}}{2}\right|^{2}=\cos^{2}(\pi\varphi)\).

(b) \(\Pr[0]-\Pr[1]=\cos(2\pi\varphi)=\mathrm{Re}\,\langle u|U|u\rangle\).

Each shot therefore gives one Bernoulli sample of a quantity whose mean encodes the phase. Estimating \(\varphi\) this way costs \(O(1/\varepsilon^{2})\) shots; full QPE costs \(O(1/\varepsilon)\) applications of \(U\), the Heisenberg-limited scaling.

Problem 6.3 Symbolic

C6.S3 — Sizing the register

(a) Give the guaranteed lower bound on the probability that \(t\)-qubit phase estimation returns the nearest \(t\)-bit approximation of \(\varphi\) (an exact expression).

\(p_{\min}=\) your answer

(b) Give the number of ancillas \(t\) needed for \(n\) bits of precision with failure probability at most \(\varepsilon\) (use n and eps; you may use ceiling).

\(t=\) your answer

(c) Evaluate it for \(n={@nn@}\) and \(\varepsilon=1/100\).

\(t=\) your answer

Show the worked solution

(a) The geometric-sum amplitude at the nearest integer satisfies \(|\alpha_b|^{2}\ge 4/\pi^{2}\approx0.405\), independently of \(t\) and \(\varphi\).

(b) Bounding the tail of the Fejér kernel gives \(t=n+\left\lceil\log_2\left(2+\frac{1}{2\varepsilon}\right)\right\rceil\).

(c) With \(n={@nn@}\), \(\varepsilon=1/100\): \(\lceil\log_2 52\rceil=6\), so \(t={@nn@}+6={@ta3@}\).

Alternatively, repeat the \(t=n\) circuit \(O(\log(1/\varepsilon))\) times and take the median — the standard powering trick, cheaper in qubits but more expensive in circuit repetitions.
