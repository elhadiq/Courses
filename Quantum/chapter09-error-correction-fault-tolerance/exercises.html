C9.Q1 — Encode, corrupt, diagnose, correct

\(\alpha|0\rangle+\beta|1\rangle\mapsto\alpha|000\rangle+\beta|111\rangle\), with syndrome \((Z_1Z_2, Z_2Z_3)\).

Write encode3(alpha, beta) returning the 8-dimensional encoded state; apply_x(state, q) applying \(X\) to qubit \(q\) (0 = most significant); syndrome3(state) returning the tuple of \(\pm1\) eigenvalues of \(Z_1Z_2\) and \(Z_2Z_3\) as ints; and correct3(state) returning the corrected state.

syndrome3(X on qubit 0) -> (-1, 1)

Show the reference solution 
import numpy as np

X = np.array([[0, 1], [1, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)
I2 = np.eye(2, dtype=complex)

def _embed(U, q, n=3):
    ops = [I2] * n
    ops[q] = U
    out = np.array([[1.0 + 0j]])
    for o in ops:
        out = np.kron(out, o)
    return out

def encode3(alpha, beta):
    v = np.zeros(8, dtype=complex)
    v[0] = alpha
    v[7] = beta
    return v

def apply_x(state, q):
    return _embed(X, q) @ np.asarray(state, dtype=complex)

def syndrome3(state):
    state = np.asarray(state, dtype=complex)
    S1 = _embed(Z, 0) @ _embed(Z, 1)
    S2 = _embed(Z, 1) @ _embed(Z, 2)
    return tuple(int(round(float(np.real(np.vdot(state, S @ state))))) for S in (S1, S2))

def correct3(state):
    s = syndrome3(state)
    table = {(1, 1): None, (-1, 1): 0, (-1, -1): 1, (1, -1): 2}
    q = table[s]
    return np.asarray(state, dtype=complex) if q is None else apply_x(state, q)

C9.Q2 — Syndromes as linear algebra over GF(2)

A Pauli on \(n\) qubits is a binary vector \((x|z)\); two Paulis commute iff \(x_1\!\cdot\!z_2+z_1\!\cdot\!x_2=0 \bmod 2\).

Show the reference solution 
import numpy as np

def commutes(p1, p2, n):
    p1 = np.asarray(p1, dtype=int)
    p2 = np.asarray(p2, dtype=int)
    s = (np.dot(p1[:n], p2[n:]) + np.dot(p1[n:], p2[:n])) % 2
    return bool(s == 0)

def syndrome(error, stabilizers, n):
    return tuple(0 if commutes(error, g, n) else 1 for g in stabilizers)

def is_valid_stabilizer_group(gens, n):
    for i in range(len(gens)):
        for j in range(i + 1, len(gens)):
            if not commutes(gens[i], gens[j], n):
                return False
    return True

def weight(pauli, n):
    pauli = np.asarray(pauli, dtype=int)
    return int(sum(1 for i in range(n) if pauli[i] or pauli[n + i]))

import numpy as np

def code_projector(basis):
    P = None
    for c in basis:
        c = np.asarray(c, dtype=complex).ravel()
        c = c / np.linalg.norm(c)
        term = np.outer(c, c.conj())
        P = term if P is None else P + term
    return P

def knill_laflamme(P, errors, tol=1e-9):
    P = np.asarray(P, dtype=complex)
    nrm = np.real(np.trace(P @ P))
    for Ea in errors:
        for Eb in errors:
            M = P @ np.asarray(Ea, dtype=complex).conj().T @ np.asarray(Eb, dtype=complex) @ P
            c = np.trace(P @ M) / nrm
            if not np.allclose(M, c * P, atol=tol):
                return False
    return True

C9.Q4 — When does error correction actually help?

A distance-\(d\) code suppresses errors as \(p_L\approx A(p/p_{\text{th}})^{\lfloor(d+1)/2\rfloor}\); concatenating \(\ell\) levels of a distance-3 code gives \(p_L\approx p_{\text{th}}(p/p_{\text{th}})^{2^{\ell}}\). Below threshold, more qubits help; above it, they hurt.

Write logical_error_surface(p, p_th, d, A=0.1); logical_error_concat(p, p_th, levels); and min_distance_for(p, p_th, target, A=0.1) returning the smallest odd \(d\ge3\) with logical_error_surface(p, p_th, d, A) <= target (search up to \(d=101\), return None if none works). Round the two error rates to 12 decimals.

logical_error_surface(1e-3, 1e-2, 3) -> 0.1 * (0.1)^2 = 0.001
min_distance_for(1e-3, 1e-2, 1e-12) -> 21

import numpy as np

def logical_error_surface(p, p_th, d, A=0.1):
    return round(float(A * (p / p_th) ** ((d + 1) // 2)), 12)

def logical_error_concat(p, p_th, levels):
    return round(float(p_th * (p / p_th) ** (2 ** levels)), 12)

def min_distance_for(p, p_th, target, A=0.1):
    if p >= p_th:
        return None
    for d in range(3, 102, 2):
        if logical_error_surface(p, p_th, d, A) <= target:
            return d
    return None

Problem 9.1 Symbolic

C9.S1 — Reading [[n,k,d]]

A stabilizer code has parameters \([[n,k,d]]\) with \(d={@d@}\).

(a) Give the number of arbitrary single-qubit errors it can correct, in terms of d (use floor).

\(t=\) your answer

(b) Give the number of independent stabilizer generators, in terms of n and k.

your answer

(c) The quantum Singleton bound reads \(n-k\ge \alpha(d-1)\). Give \(\alpha\).

\(\alpha=\) your answer

Show the worked solution

(a) \(t=\lfloor (d-1)/2\rfloor\). For \(d={@d@}\) this is \({@ta1@}\). A distance-\(d\) code detects \(d-1\) errors but only corrects half that many, since two correctable errors must map the code space to distinguishable subspaces.

(b) The code space is the joint \(+1\) eigenspace of \(n-k\) independent generators, each halving the dimension: \(2^{n}/2^{n-k}=2^{k}\).

(c) \(\alpha=2\): the quantum Singleton bound is \(n-k\ge2(d-1)\), twice the classical one, because both bit and phase errors must be corrected. Codes meeting it with equality are called quantum MDS; the \([[5,1,3]]\) code is an example.

Problem 9.2 Symbolic

C9.S2 — The threshold theorem, quantitatively

For a distance-\(d\) surface code, \(p_L\approx A\,(p/p_{\mathrm{th}})^{(d+1)/2}\) with \(d\) odd.

(a) Give \(p_L\) for \(A=1\), \(p_{\mathrm{th}}=10^{-2}\), \(p=10^{-3}\) and \(d={@d@}\) (exact expression, no decimals).

\(p_L=\) your answer

(b) Concatenating \(\ell\) levels of a distance-3 code gives \(p_L=p_{\mathrm{th}}(p/p_{\mathrm{th}})^{e(\ell)}\). Give the exponent \(e(\ell)\) in terms of l.

\(e(\ell)=\) your answer

(c) Give the number of physical qubits per logical qubit for a distance-\(d\) surface code (leading order, in terms of d).

your answer

Show the worked solution

(a) The exponent is \((d+1)/2\); with \(p/p_{\mathrm{th}}=10^{-1}\) this gives \(p_L=10^{-(d+1)/2}={@ta1@}\).

(b) Each concatenation level squares the ratio, so \(e(\ell)=2^{\ell}\): the suppression is doubly exponential in the number of levels, and only \(\mathrm{polylog}\) levels are needed for any target — the content of the threshold theorem.

(c) \(d^{2}\) (or \(2d^{2}-1\) counting ancillas, depending on the layout). At \(p/p_{\mathrm{th}}=1/10\) and a target of \(10^{-12}\), \(d\approx23\), so roughly \(500\)–\(1000\) physical qubits per logical qubit — before accounting for magic state factories, which typically dominate the total footprint.

Problem 9.3 Symbolic

C9.S3 — Counting states and syndromes

The Steane code is \([[7,1,3]]\).

(a) Give the number of independent stabilizer generators.

your answer

(b) Give the number of distinct non-trivial syndromes available, and compare with the number of weight-1 Pauli errors on 7 qubits. Enter the ordered pair [syndromes, errors].

your answer

(c) For a general \([[n,1,3]]\) code, the quantum Hamming bound requires \(2^{n-1}\ge 1+3n\). Give the smallest \(n\) satisfying it.

\(n=\) your answer

Show the worked solution

(a) \(n-k=7-1=6\).

(b) Six generators give \(2^{6}=64\) syndromes, of which \(63\) are non-trivial. There are \(3\times7=21\) weight-1 Pauli errors, so the syndromes are far from exhausted — the Steane code is not perfect. (It is, however, CSS and admits transversal Clifford gates, which matters more in practice.)

(c) \(2^{n-1}\ge 1+3n\): at \(n=5\), \(16\ge16\) holds with equality, so \(n=5\). That is the \([[5,1,3]]\) perfect code, which saturates the bound — every non-trivial syndrome corresponds to exactly one correctable error.
