C10.Q1 — The input format of every variational algorithm

A Hamiltonian is given as a list of (Pauli string, coefficient) pairs. Its expectation value on a state is the weighted sum of the individual Pauli expectations — exactly what a device measures.

Show the reference solution 
import numpy as np

I2 = np.eye(2, dtype=complex)
X = np.array([[0, 1], [1, 0]], dtype=complex)
Y = np.array([[0, -1j], [1j, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)
PAULI = {'I': I2, 'X': X, 'Y': Y, 'Z': Z}

def pauli_string(s):
    out = np.array([[1.0 + 0j]])
    for ch in s:
        out = np.kron(out, PAULI[ch])
    return out

def hamiltonian(terms):
    n = len(terms[0][0])
    H = np.zeros((2 ** n, 2 ** n), dtype=complex)
    for s, c in terms:
        H = H + c * pauli_string(s)
    return H

def expectation(psi, H):
    psi = np.asarray(psi, dtype=complex).ravel()
    psi = psi / np.linalg.norm(psi)
    return round(float(np.real(np.vdot(psi, np.asarray(H, dtype=complex) @ psi))), 6)

def ground_energy(H):
    H = np.asarray(H, dtype=complex)
    return round(float(np.linalg.eigvalsh((H + H.conj().T) / 2)[0]), 6)

C10.Q2 — A complete variational loop

For \(U(\theta)=e^{-i\theta P/2}\) with \(P^{2}=I\), \(\partial_\theta\langle A\rangle=\tfrac12[\langle A\rangle_{\theta+\pi/2}-\langle A\rangle_{\theta-\pi/2}]\) exactly.

import numpy as np

def _ry(theta):
    c, s = np.cos(theta / 2), np.sin(theta / 2)
    return np.array([[c, -s], [s, c]], dtype=complex)

def _state(theta):
    return _ry(theta) @ np.array([1, 0], dtype=complex)

def energy(theta, H):
    psi = _state(theta)
    return round(float(np.real(np.vdot(psi, np.asarray(H, dtype=complex) @ psi))), 6)

def _raw_energy(theta, H):
    psi = _state(theta)
    return float(np.real(np.vdot(psi, np.asarray(H, dtype=complex) @ psi)))

def grad_parameter_shift(theta, H):
    return round(0.5 * (_raw_energy(theta + np.pi / 2, H)
                        - _raw_energy(theta - np.pi / 2, H)), 6)

def vqe(H, theta0, lr=0.3, steps=300):
    th = float(theta0)
    for _ in range(steps):
        g = 0.5 * (_raw_energy(th + np.pi / 2, H) - _raw_energy(th - np.pi / 2, H))
        th = th - lr * g
    return (th, energy(th, H))

C10.Q3 — Combinatorial optimisation, variationally

MaxCut on a graph \(G=(V,E)\) maximises \(C=\sum_{(i,j)\in E}\tfrac12(1-z_iz_j)\). Encode it as \(H_C=\sum_{(i,j)\in E}\tfrac12(I-Z_iZ_j)\), and use the mixer \(H_M=\sum_i X_i\).

import numpy as np
from itertools import product

I2 = np.eye(2, dtype=complex)
X = np.array([[0, 1], [1, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)

def _embed(U, q, n):
    ops = [I2] * n
    ops[q] = U
    out = np.array([[1.0 + 0j]])
    for o in ops:
        out = np.kron(out, o)
    return out

def maxcut_hamiltonian(n, edges):
    H = np.zeros((2 ** n, 2 ** n), dtype=complex)
    for i, j in edges:
        H = H + 0.5 * (np.eye(2 ** n, dtype=complex) - _embed(Z, i, n) @ _embed(Z, j, n))
    return H

def _expm_diag(H, t):
    w, v = np.linalg.eigh((H + H.conj().T) / 2)
    return (v * np.exp(-1j * t * w)) @ v.conj().T

def qaoa_state(n, edges, gamma, beta):
    HC = maxcut_hamiltonian(n, edges)
    HM = np.zeros((2 ** n, 2 ** n), dtype=complex)
    for i in range(n):
        HM = HM + _embed(X, i, n)
    psi = np.full(2 ** n, 1 / np.sqrt(2 ** n), dtype=complex)
    psi = _expm_diag(HC, gamma) @ psi
    psi = _expm_diag(HM, beta) @ psi
    return psi

def qaoa_expectation(n, edges, gamma, beta):
    psi = qaoa_state(n, edges, gamma, beta)
    HC = maxcut_hamiltonian(n, edges)
    return round(float(np.real(np.vdot(psi, HC @ psi))), 6)

def best_cut(n, edges):
    best = 0
    for bits in product([0, 1], repeat=n):
        cut = sum(1 for i, j in edges if bits[i] != bits[j])
        best = max(best, cut)
    return best

C10.Q4 — Error mitigation, and what it costs

Zero-noise extrapolation measures an observable at several amplified noise levels \(\lambda_k\) and extrapolates to \(\lambda=0\). Richardson extrapolation is polynomial interpolation evaluated at zero.

Write richardson(lams, vals) returning the value at \(\lambda=0\) of the interpolating polynomial through the given points (use the Lagrange formula, no numpy.polyfit required but allowed), rounded to 6 decimals; and shots_needed(variance, eps) returning \(\lceil \mathrm{Var}/\varepsilon^{2}\rceil\) as an int — the sampling cost of estimating an expectation value to additive error \(\varepsilon\).

import numpy as np
from math import ceil

def richardson(lams, vals):
    lams = [float(x) for x in lams]
    vals = [float(v) for v in vals]
    total = 0.0
    for i, (li, vi) in enumerate(zip(lams, vals)):
        term = vi
        for j, lj in enumerate(lams):
            if i != j:
                term *= (0.0 - lj) / (li - lj)
        total += term
    return round(total, 6)

def shots_needed(variance, eps):
    return int(ceil(float(variance) / float(eps) ** 2))

(c) A BQP algorithm has success probability \(2/3\). By the Chernoff bound, the number of repetitions needed for failure probability \(\delta\) scales as \(c\cdot\log(1/\delta)\). Give the exponent \(\alpha\) in "repetitions \(=\Theta(\log^{\alpha}(1/\delta))\)".

\(\alpha=\) your answer

Show the worked solution

(a) The Pauli strings \(\sigma_{\mu_1}\otimes\cdots\otimes\sigma_{\mu_n}\) with \(\mu_i\in\{I,X,Y,Z\}\) number \(4^{n}\), and they form an orthogonal basis of the \(4^{n}\)-dimensional real space of Hermitian operators.

(b) For \(n={@n@}\): \({@ta2@}\).

(c) \(\alpha=1\): majority voting over \(O(\log(1/\delta))\) runs suffices, so the constant \(2/3\) in the definition of BQP is arbitrary. Physically relevant Hamiltonians are \(k\)-local with only \(O(n^{k})\) terms — the exponential count above is why arbitrary Hamiltonians are hopeless and structure is everything.

Problem 10.2 Symbolic

C10.S2 — Exact gradients from shifted circuits

Let \(U(\theta)=e^{-i\theta P/2}\) with \(P^{2}=I\), and let \(f(\theta)=\langle 0|U^{\dagger}(\theta)\,A\,U(\theta)|0\rangle\).

(a) Write \(U(\theta)\) in the form \(\alpha(\theta)I-i\beta(\theta)P\) and give \(\alpha(\theta)\).

\(\alpha(\theta)=\) your answer

(b) The parameter-shift rule reads \(f\'(\theta)=r\,[f(\theta+s)-f(\theta-s)]\). Give the ordered pair [r, s].

your answer

(c) \(f\) is a trigonometric polynomial in \(\theta\). Give its period.

your answer

Show the worked solution

(a) Since \(P^2=I\), splitting the exponential series gives \(U(\theta)=\cos(\theta/2)I-i\sin(\theta/2)P\), so \(\alpha=\cos(\theta/2)\) — the same identity as in Chapter 1.

(b) Expanding, \(f(\theta)=a+b\cos\theta+c\sin\theta\). Then \(f(\theta+\pi/2)-f(\theta-\pi/2)=-2b\sin\theta+2c\cos\theta=2f\'(\theta)\), so \(r=1/2\) and \(s=\pi/2\).

(c) \(2\pi\), from the same expansion.

Note the rule is exact, not a finite-difference approximation: it evaluates the same circuit at two shifted parameter values, so it adds no depth and introduces no discretisation bias — only shot noise.

Problem 10.3 Symbolic

C10.S3 — Why NISQ is hard, quantitatively

(a) Estimating \(\langle A\rangle\) with \(A^{2}=I\) to additive error \(\varepsilon\) requires how many shots, at leading order in eps? (Use variance \(\le 1\).)

your answer

(b) A chemistry Hamiltonian has \(M\) Pauli terms measured independently, each to error \(\varepsilon/\sqrt M\). Give the total shot count in terms of M and eps.

your answer

(c) In a barren plateau the gradient variance scales as \(2^{-n}\). Give the number of shots needed to resolve the gradient sign, in terms of n (leading order).

your answer

Show the worked solution

(a) The sample mean of a bounded random variable has standard error \(\sigma/\sqrt N\), so \(N=\Theta(1/\varepsilon^{2})\).

(b) Each of the \(M\) terms needs \(M/\varepsilon^{2}\) shots, for a total of \(M^{2}/\varepsilon^{2}\). With \(M=O(n^{4})\) spin-orbital terms and chemical accuracy \(\varepsilon=1.6\times10^{-3}\) Ha, this reaches \(10^{9}\)–\(10^{12}\) shots for molecules of interest — the arithmetic behind most scepticism about near-term VQE. Grouping commuting terms into cliques reduces \(M\), but not the asymptotic form.

(c) Resolving a quantity of size \(2^{-n/2}\) needs \(N\sim2^{n}\) shots: gradient estimation becomes exponentially expensive, which is exactly the barren-plateau obstruction. Note that this is a statement about trainability, independent of whether the ansatz could in principle represent the ground state.
