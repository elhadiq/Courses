C2.Q1 — From amplitudes to the Bloch sphere

The Bloch vector \(\vec r=(\langle X\rangle,\langle Y\rangle,\langle Z\rangle)\) is the coordinate system in which single-qubit gates become rotations.

Write bloch_vector(psi) returning a tuple of three floats (each rounded to 6 decimals) for a normalised 2-component state vector, and state_from_angles(theta, phi) returning the NumPy array \((\cos\tfrac\theta2,\ e^{i\varphi}\sin\tfrac\theta2)\).

bloch_vector([1, 0])             -> (0.0, 0.0, 1.0)
bloch_vector([1, 1]/sqrt(2))     -> (1.0, 0.0, 0.0)
bloch_vector([1, 1j]/sqrt(2))    -> (0.0, 1.0, 0.0)

    ...

def state_from_angles(theta, phi):
    ...

Worked examples

import numpy as np
print(bloch_vector([1, 0]))
→ (0.0, 0.0, 1.0)
import numpy as np
print(bloch_vector(np.array([1, 1])/np.sqrt(2)))
→ (1.0, 0.0, 0.0)
Show the reference solution 
import numpy as np

X = np.array([[0, 1], [1, 0]], dtype=complex)
Y = np.array([[0, -1j], [1j, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)

def bloch_vector(psi):
    psi = np.asarray(psi, dtype=complex).reshape(2)
    psi = psi / np.linalg.norm(psi)
    return tuple(round(float(np.real(psi.conj() @ (S @ psi))), 6) for S in (X, Y, Z))

def state_from_angles(theta, phi):
    return np.array([np.cos(theta / 2), np.exp(1j * phi) * np.sin(theta / 2)], dtype=complex)

C2.Q2 — Verifying the SU(2) → SO(3) homomorphism

\(R_{\hat n}(\theta)=\cos\tfrac\theta2 I-i\sin\tfrac\theta2(\hat n\cdot\vec\sigma)\) rotates the Bloch vector by \(\theta\) about \(\hat n\). This exercise checks that claim numerically.

Show the reference solution 
import numpy as np

X = np.array([[0, 1], [1, 0]], dtype=complex)
Y = np.array([[0, -1j], [1j, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)
I2 = np.eye(2, dtype=complex)

def rot(n, theta):
    n = np.asarray(n, dtype=float)
    n = n / np.linalg.norm(n)
    ns = n[0] * X + n[1] * Y + n[2] * Z
    return np.cos(theta / 2) * I2 - 1j * np.sin(theta / 2) * ns

def rotate_bloch(n, theta, r):
    n = np.asarray(n, dtype=float); n = n / np.linalg.norm(n)
    r = np.asarray(r, dtype=float)
    return (r * np.cos(theta) + np.cross(n, r) * np.sin(theta)
            + n * np.dot(n, r) * (1 - np.cos(theta)))

C2.Q3 — Born rule and state collapse

Given an orthonormal basis \(\{|b_k\rangle\}\), outcome \(k\) occurs with probability \(|\langle b_k|\psi\rangle|^{2}\) and the state collapses to \(|b_k\rangle\).

Write born_probs(psi, basis) where basis is a matrix whose columns are the basis vectors, returning a NumPy array of probabilities (rounded to 8 decimals, summing to 1); and post_measurement(psi, basis, k) returning the normalised collapsed state.

psi = |0>, basis = columns [|+>, |->]  ->  [0.5, 0.5]

Show the reference solution 
import numpy as np

def born_probs(psi, basis):
    psi = np.asarray(psi, dtype=complex).ravel()
    psi = psi / np.linalg.norm(psi)
    B = np.asarray(basis, dtype=complex)
    amps = B.conj().T @ psi
    return np.round(np.abs(amps) ** 2, 8)

def post_measurement(psi, basis, k):
    B = np.asarray(basis, dtype=complex)
    v = B[:, k]
    return v / np.linalg.norm(v)

C2.Q4 — What a quantum computer actually outputs

A device returns samples, not amplitudes. Estimating \(\langle Z\rangle\) from \(N\) shots incurs an error \(\Theta(1/\sqrt N)\); distinguishing non-orthogonal states is capped by the Helstrom bound.

Write sample_counts(psi, shots, seed) returning a dict mapping bit-strings (MSB = qubit 0, zero-padded to \(n\) characters) to counts, sorted by key, using numpy.random.default_rng(seed).choice; and helstrom(psi, phi) returning the optimal success probability \(\tfrac12(1+\sqrt{1-|\langle\psi|\phi\rangle|^{2}})\), rounded to 6 decimals.

helstrom(|0>, |0>)  ->  0.5      (indistinguishable)
helstrom(|0>, |1>)  ->  1.0      (orthogonal)
helstrom(|0>, |+>)  ->  0.853553

Starting point

    ...

def helstrom(psi, phi):
    ...

Worked examples

print(helstrom([1,0], [0,1]), helstrom([1,0], [1,0]))
→ 1.0 0.5

print(helstrom([1,0], np.array([1,1])/np.sqrt(2)))
→ 0.853553
Show the reference solution 
import numpy as np

def sample_counts(psi, shots, seed):
    psi = np.asarray(psi, dtype=complex).ravel()
    probs = np.abs(psi) ** 2
    probs = probs / probs.sum()
    n = int(round(np.log2(len(probs))))
    rng = np.random.default_rng(seed)
    idx = rng.choice(len(probs), size=shots, p=probs)
    counts = {}
    for i in idx:
        key = format(int(i), '0{}b'.format(n))
        counts[key] = counts.get(key, 0) + 1
    return dict(sorted(counts.items()))

def helstrom(psi, phi):
    a = np.asarray(psi, dtype=complex).ravel(); a = a / np.linalg.norm(a)
    b = np.asarray(phi, dtype=complex).ravel(); b = b / np.linalg.norm(b)
    ov = abs(np.vdot(a, b)) ** 2
    return round(0.5 * (1 + np.sqrt(max(0.0, 1 - ov))), 6)

Problem 2.1 Symbolic

C2.S1 — Born rule on the Bloch sphere

A qubit is prepared in \(|\psi\rangle=\cos(\theta/2)|0\rangle+e^{i\varphi}\sin(\theta/2)|1\rangle\).

Give the probability of obtaining the outcome \(+1\) when the observable \(X\) is measured, as a simplified function of theta and phi.

\(p_{+}=\) your answer

Show the worked solution

The \(+1\) eigenvector of \(X\) is \(|+\rangle=(|0\rangle+|1\rangle)/\sqrt2\), so

\[ p_{+}=|\langle +|\psi\rangle|^{2}=\tfrac12\left|\cos\tfrac\theta2+e^{i\varphi}\sin\tfrac\theta2\right|^{2}. \]

Expanding, \(p_+=\tfrac12\big(1+2\cos\tfrac\theta2\sin\tfrac\theta2\cos\varphi\big)=\tfrac12(1+\sin\theta\cos\varphi)\).

Geometrically this is \(p_\pm=\tfrac12(1\pm\hat n\cdot\vec r)\) with \(\hat n=\hat x\): the probability is an affine function of the projection of the Bloch vector onto the measurement axis.

Problem 2.2 Symbolic

C2.S2 — Uncertainty

For the state \(|0\rangle\):

(a) Give \(\Delta X=\sqrt{\langle X^2\rangle-\langle X\rangle^2}\).

\(\Delta X=\) your answer

(b) Give the Robertson lower bound \(\tfrac12|\langle[X,Y]\rangle|\) for this state.

bound \(=\) your answer

Show the worked solution

(a) \(X^2=I\) so \(\langle X^2\rangle=1\); and \(\langle 0|X|0\rangle=0\). Hence \(\Delta X=1\). By symmetry \(\Delta Y=1\) as well.

(b) \([X,Y]=2iZ\) and \(\langle 0|Z|0\rangle=1\), so the bound is \(\tfrac12|2i\cdot 1|=1\).

Since \(\Delta X\Delta Y=1\) equals the bound, \(|0\rangle\) is a minimum-uncertainty state for the pair \((X,Y)\) — the qubit analogue of a coherent state.

Problem 2.3 Symbolic

C2.S3 — Optimal state discrimination

Two equally likely pure states satisfy \(\langle\psi_0|\psi_1\rangle=\cos\alpha\) with \(\alpha\in[0,\pi/2]\).

(a) Give the maximal probability of correctly identifying the prepared state, as a simplified function of alpha.

\(p_{\max}=\) your answer

(b) Evaluate it for \(\alpha=\pi/4\) (exact expression, no decimals).

\(p_{\max}(\pi/4)=\) your answer

Show the worked solution

(a) The Helstrom bound for equal priors and pure states is \(p_{\max}=\tfrac12\big(1+\sqrt{1-|\langle\psi_0|\psi_1\rangle|^{2}}\big)\). With overlap \(\cos\alpha\) and \(\alpha\in[0,\pi/2]\), \(\sqrt{1-\cos^2\alpha}=\sin\alpha\), so \(p_{\max}=\tfrac12(1+\sin\alpha)\).

(b) At \(\alpha=\pi/4\): \(p_{\max}=\tfrac12\left(1+\tfrac{\sqrt2}{2}\right)=\tfrac{2+\sqrt2}{4}\approx0.8536\).

Only orthogonal states (\(\alpha=\pi/2\)) give \(p_{\max}=1\); identical states give \(1/2\), i.e. a coin flip. This is the quantitative form of the statement that non-orthogonal states cannot be reliably distinguished, and it underpins BB84.
