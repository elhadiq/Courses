C8.Q1 — Two reflections make a rotation

\(G=D\,O_f\) rotates the state by \(2\theta\) in the good/bad plane, with \(\sin\theta=\sqrt{M/N}\).

import numpy as np

def grover_operator(N, marked):
    O = np.eye(N, dtype=complex)
    for m in marked:
        O[m, m] = -1
    psi = np.full(N, 1 / np.sqrt(N), dtype=complex)
    D = 2 * np.outer(psi, psi.conj()) - np.eye(N, dtype=complex)
    return D @ O

def optimal_iterations(N, M):
    theta = np.arcsin(np.sqrt(M / N))
    return int(np.floor(np.pi / (4 * theta)))

def success_probability(N, M, k):
    theta = np.arcsin(np.sqrt(M / N))
    return round(float(np.sin((2 * k + 1) * theta) ** 2), 6)

C8.Q2 — The periodicity of the success probability

Because \(G\) is a rotation, iterating past \(k_{\text{opt}}\) decreases the success probability — a purely quantum failure mode with no classical analogue.

import numpy as np

def _G(N, marked):
    O = np.eye(N, dtype=complex)
    for m in marked:
        O[m, m] = -1
    psi = np.full(N, 1 / np.sqrt(N), dtype=complex)
    return (2 * np.outer(psi, psi.conj()) - np.eye(N, dtype=complex)) @ O

def run_grover(N, marked, k):
    G = _G(N, marked)
    psi = np.full(N, 1 / np.sqrt(N), dtype=complex)
    for _ in range(k):
        psi = G @ psi
    return psi

def marked_probability(psi, marked):
    psi = np.asarray(psi, dtype=complex)
    return round(float(sum(abs(psi[m]) ** 2 for m in marked)), 6)

def best_k(N, marked, kmax):
    G = _G(N, marked)
    psi = np.full(N, 1 / np.sqrt(N), dtype=complex)
    best, bp = 0, marked_probability(psi, marked)
    for k in range(1, kmax + 1):
        psi = G @ psi
        pk = marked_probability(psi, marked)
        if pk > bp:
            best, bp = k, pk
    return best

C8.Q3 — Beyond the uniform superposition

Replace \(H^{\otimes n}\) by any \(A\) with \(A|0\rangle=|\psi\rangle\). Then \(Q=-A S_0 A^{\dagger} S_f\) amplifies the good component at the same quadratic rate, with \(\sin\theta=\|\Pi_{\text{good}}|\psi\rangle\|\).

import numpy as np

def amplitude_amplification_operator(A, marked):
    A = np.asarray(A, dtype=complex)
    N = A.shape[0]
    S0 = np.eye(N, dtype=complex)
    S0[0, 0] = -1
    Sf = np.eye(N, dtype=complex)
    for m in marked:
        Sf[m, m] = -1
    return -A @ S0 @ A.conj().T @ Sf

def amplify(A, marked, k):
    A = np.asarray(A, dtype=complex)
    N = A.shape[0]
    e0 = np.zeros(N, dtype=complex)
    e0[0] = 1
    psi = A @ e0
    Q = amplitude_amplification_operator(A, marked)
    for _ in range(k):
        psi = Q @ psi
    return psi

C8.Q4 — Estimating M without finding a marked item

The Grover iterate has eigenvalues \(e^{\pm2i\theta}\) on the good/bad plane. Phase estimation on \(G\) therefore returns \(\theta\), and \(M=N\sin^{2}\theta\).

import numpy as np

def grover_angle(N, M):
    return float(np.arcsin(np.sqrt(M / N)))

def counting_estimate(N, y, t):
    return round(float(N * np.sin(np.pi * y / 2 ** t) ** 2), 4)

def counting_error_bound(N, M, t):
    K = 2 ** t
    return round(float(2 * np.pi * np.sqrt(M * (N - M)) / K + np.pi ** 2 * N / K ** 2), 4)

Problem 8.1 Symbolic

C8.S1 — Sizing a Grover search

Let \(N=2^{ {@n@} }\) and let there be \(M={@M@}\) marked items. Write \(\theta=\arcsin\sqrt{M/N}\).

(a) Give the success probability after \(k\) iterations, as a function of k and theta.

\(p_k=\) your answer

(b) Give the leading-order optimal number of iterations (ignoring the floor), in terms of N and M.

\(k_{\mathrm{opt}}\approx\) your answer

(c) Evaluate that expression numerically for the values above (exact expression, no decimals).

your answer

Show the worked solution

(a) \(G\) rotates by \(2\theta\) in the good/bad plane starting at angle \(\theta\), so after \(k\) steps the good amplitude is \(\sin((2k+1)\theta)\) and \(p_k=\sin^{2}((2k+1)\theta)\).

(b) Solving \((2k+1)\theta=\pi/2\) gives \(k=\frac{\pi}{4\theta}-\frac12\); for \(M\ll N\), \(\theta\approx\sqrt{M/N}\) and \(k_{\mathrm{opt}}\approx\frac{\pi}{4}\sqrt{N/M}\).

(c) With \(N=2^{ {@n@} }\) and \(M={@M@}\): \(k\approx{@ta3@}\).

Note \(p_k\) is periodic in \(k\): running too long rotates past the target and lowers the success probability. This is why the number of iterations must be chosen in advance, and why unknown \(M\) requires the BBHT exponential schedule.

Problem 8.2 Symbolic

C8.S2 — The geometry of the Grover iterate

(a) The product of reflections about two lines meeting at angle \(\alpha\) is a rotation. Give the rotation angle in terms of alpha.

your answer

(b) Give the two eigenvalues of the Grover iterate restricted to the good/bad plane, as an ordered list, in terms of theta (use %e and %i).

your answer

(c) Amplitude estimation with \(K\) applications of \(G\) estimates \(a=\sin^2\theta\) to additive error scaling as \(K^{-\gamma}\) at leading order. Give \(\gamma\).

\(\gamma=\) your answer

Show the worked solution

(a) \(2\alpha\). Applied with \(\alpha=\theta\) (the angle between \(|\text{bad}\rangle\) and \(|\psi\rangle\)) this gives the \(2\theta\) rotation per Grover step.

(b) A planar rotation by \(2\theta\) has eigenvalues \(e^{\pm 2i\theta}\).

(c) \(\gamma=1\): the error is \(O(1/K)\), quadratically better than the \(O(1/\sqrt K)\) of classical Monte Carlo. This is the same Heisenberg scaling as phase estimation in Chapter 6 — unsurprising, since amplitude estimation is phase estimation applied to \(G\).

Problem 8.3 Symbolic

C8.S3 — Lower bounds and cryptographic consequences

(a) Give the BBBV lower bound on the number of oracle queries needed to search \(N\) items with bounded error, as a function of N (give the growth rate, e.g. sqrt(N)).

your answer

(b) A symmetric cipher has a \(b\)-bit key. Give the number of Grover iterations needed for exhaustive key search, in terms of b (leading order, ignoring the \(\pi/4\)).

your answer

(c) Give the key length \(b\) needed so that a Grover attack costs at least \(2^{ {@s@} }\) iterations.

\(b=\) your answer

Show the worked solution

(a) \(\Omega(\sqrt N)\), by the hybrid argument: after \(T\) queries the algorithm can only have distinguished the flipped oracle if \(T=\Omega(\sqrt N)\). Grover matches it, so unstructured search is settled up to constants.

(b) \(N=2^{b}\), so \(\sqrt N=2^{b/2}\) iterations.

(c) \(2^{b/2}\ge 2^{ {@s@} }\) requires \(b\ge {@ta3@}\).

This is the origin of the "double your symmetric key length" rule for post-quantum security: AES-256 retains roughly 128 bits of security against Grover. Note the rule is conservative — Grover parallelises badly, and the fault-tolerant constant factors are enormous, so the effective margin is larger than the bare exponent suggests.
