C7.Q1 — Recovering s/r from a noisy estimate

Phase estimation returns \(x=y/2^{t}\) with \(|x-s/r|\le1/(2r^{2})\). Legendre's theorem guarantees \(s/r\) is a convergent of the continued-fraction expansion of \(x\).

from fractions import Fraction

def cf_expansion(x, depth):
    # work in exact rational arithmetic: floating-point recurrences are unstable here
    x = Fraction(x).limit_denominator(10 ** 6)
    out = []
    for _ in range(depth):
        a = x.numerator // x.denominator
        out.append(a)
        x = x - a
        if x == 0:
            break
        x = 1 / x
    return out

def convergents(x, depth):
    a = cf_expansion(x, depth)
    res, pm1, pm2, qm1, qm2 = [], 1, 0, 0, 1
    for ak in a:
        pk = ak * pm1 + pm2
        qk = ak * qm1 + qm2
        res.append((pk, qk))
        pm2, pm1 = pm1, pk
        qm2, qm1 = qm1, qk
    return res

def best_denominator(x, qmax):
    best = 1
    for _, q in convergents(x, 40):
        if 0 < q <= qmax:
            best = q
    return best

C7.Q2 — From r to a non-trivial divisor

If \(r=\mathrm{ord}_N(a)\) is even and \(a^{r/2}\not\equiv-1\), then \(\gcd(a^{r/2}\pm1,N)\) are proper factors.

from math import gcd
import random

def order(a, N):
    r, x = 1, a % N
    while x != 1:
        x = (x * a) % N
        r += 1
    return r

def factors_from_order(a, r, N):
    if r % 2 != 0:
        return None
    h = pow(a, r // 2, N)
    if h == N - 1:
        return None
    f = tuple(sorted({gcd(h - 1, N), gcd(h + 1, N)} - {1, N}))
    if len(f) != 2:
        cand = [d for d in (gcd(h - 1, N), gcd(h + 1, N)) if 1 < d < N]
        if not cand:
            return None
        d = cand[0]
        return tuple(sorted((d, N // d)))
    return f

def shor_classical(N, seed):
    rng = random.Random(seed)
    while True:
        a = rng.randrange(2, N)
        g = gcd(a, N)
        if g > 1:
            return tuple(sorted((g, N // g)))
        f = factors_from_order(a, order(a, N), N)
        if f:
            return f

C7.Q3 — The quantum subroutine, exactly

Phase estimation on \(U_a|x\rangle=|ax\bmod N\rangle\) starting from \(|1\rangle\) samples \(s\) uniformly in \(\{0,\dots,r-1\}\) and outputs \(y\) distributed as a Fejér kernel around \(2^{t}s/r\).

Write phase_distribution(r, t) returning the exact distribution over the \(2^{t}\) outcomes \(y\), averaged uniformly over \(s=0,\dots,r-1\); and sample_order(a, N, t, seed, trials) which draws trials outcomes from that distribution, converts each to a candidate denominator by continued fractions, and returns the smallest candidate \(r'\) with \(a^{r'}\equiv1\pmod N\) (or None).

sample_order(7, 15, 8, 0, 20) -> 4

import numpy as np
from fractions import Fraction

def phase_distribution(r, t):
    N = 2 ** t
    y = np.arange(N)
    total = np.zeros(N)
    for s in range(r):
        d = s / r - y / N
        amp = np.where(np.abs(np.sin(np.pi * d)) < 1e-14, 1.0,
                       np.sin(np.pi * N * d) / (N * np.sin(np.pi * d)))
        total += amp ** 2
    return total / r

def sample_order(a, N, t, seed, trials):
    r_true = 1
    x = a % N
    while x != 1:
        x = (x * a) % N
        r_true += 1
    pr = phase_distribution(r_true, t)
    pr = pr / pr.sum()
    rng = np.random.default_rng(seed)
    ys = rng.choice(2 ** t, size=trials, p=pr)
    cands = []
    for y in ys:
        q = Fraction(int(y), 2 ** t).limit_denominator(N).denominator
        if q > 0 and pow(a, q, N) == 1:
            cands.append(q)
    return min(cands) if cands else None

C7.Q4 — Putting it together

import numpy as np
from math import gcd, ceil, log2
from fractions import Fraction
import random

def _phase_distribution(r, t):
    N = 2 ** t
    y = np.arange(N)
    total = np.zeros(N)
    for s in range(r):
        d = s / r - y / N
        amp = np.where(np.abs(np.sin(np.pi * d)) < 1e-14, 1.0,
                       np.sin(np.pi * N * d) / (N * np.sin(np.pi * d)))
        total += amp ** 2
    return total / r

def _true_order(a, N):
    r, x = 1, a % N
    while x != 1:
        x = (x * a) % N
        r += 1
    return r

def shor(N, seed, t=None, trials=30):
    if N % 2 == 0:
        return tuple(sorted((2, N // 2)))
    if t is None:
        t = 2 * int(ceil(log2(N))) + 1
    rng = random.Random(seed)
    nprng = np.random.default_rng(seed)
    while True:
        a = rng.randrange(2, N)
        g = gcd(a, N)
        if g > 1:
            return tuple(sorted((g, N // g)))
        pr = _phase_distribution(_true_order(a, N), t)
        pr = pr / pr.sum()
        for y in nprng.choice(2 ** t, size=trials, p=pr):
            r = Fraction(int(y), 2 ** t).limit_denominator(N).denominator
            if r == 0 or pow(a, r, N) != 1 or r % 2:
                continue
            h = pow(a, r // 2, N)
            if h == N - 1:
                continue
            for d in (gcd(h - 1, N), gcd(h + 1, N)):
                if 1 < d < N:
                    return tuple(sorted((d, N // d)))

Problem 7.1 Symbolic

C7.S1 — The arithmetic of the reduction

Take \(N=15\) and \(a=7\).

(a) Give \(r=\mathrm{ord}_{15}(7)\).

\(r=\) your answer

(b) Give \(7^{r/2}\bmod 15\).

your answer

(c) Give the two non-trivial factors \(\gcd(7^{r/2}\pm1,15)\), as an ordered list [smaller, larger].

your answer

Show the worked solution

(a) \(7^1=7,\ 7^2=49\equiv4,\ 7^3\equiv28\equiv13,\ 7^4\equiv91\equiv1\pmod{15}\), so \(r=4\).

(b) \(7^{2}=49\equiv4\pmod{15}\). Crucially \(4\not\equiv-1\equiv14\), so the reduction succeeds.

(c) \(\gcd(3,15)=3\) and \(\gcd(5,15)=5\), giving \(15=3\cdot5\).

Had we drawn \(a=14\), we would have \(r=2\) and \(14^{1}\equiv-1\), the failure case — which is why the algorithm retries with a fresh random \(a\). The failure probability is at most \(1/2\) per attempt.

Problem 7.2 Symbolic

C7.S2 — Sizing the ancilla register

Order finding must resolve \(s/r\) with \(r

(a) Legendre\'s theorem requires \(|x-s/r|\le\varepsilon\). Give the largest \(\varepsilon\) that still determines \(s/r\) uniquely, in terms of r.

\(\varepsilon=\) your answer

(b) Give the number of ancilla qubits \(t\) that guarantees this for every \(rL.

\(t=\) your answer

(c) Evaluate \(t\) for an \(L={@L@}\)-bit modulus.

\(t=\) your answer

Show the worked solution

(a) \(\varepsilon=\frac{1}{2r^{2}}\): two distinct rationals with denominators below \(r\) differ by at least \(1/r^{2}\), so half that gap identifies the right one.

(b) Since \(r<2^{L}\), it suffices that \(2^{-t}\le 2^{-(2L+1)}\), i.e. \(t=2L+1\).

(c) For \(L={@L@}\): \(t=2\cdot{@L@}+1={@ta3@}\).

For RSA-2048 this is \(t=4097\) ancillas on top of the arithmetic register — before any error-correction overhead. Fault-tolerant estimates instead use windowed arithmetic and semi-classical Fourier readout to bring the logical qubit count down to roughly \(3L\).

Problem 7.3 Symbolic

C7.S3 — How often must we retry?

Assume each independent attempt of Shor\'s algorithm succeeds with probability at least \(1/2\).

(a) Give the probability that at least one of \(k\) independent attempts succeeds, as a function of k (using the worst case \(1/2\)).

\(p_k=\) your answer

(b) Give the smallest \(k\) with \(p_k\ge 1-2^{-{@m@}}\).

\(k=\) your answer

(c) Phase estimation returns \(s=0\) with probability \(1/r\), which yields no information. For \(r={@r0@}\), give that probability.

your answer

Show the worked solution

(a) Failures are independent, so \(p_k=1-2^{-k}\).

(b) \(1-2^{-k}\ge1-2^{-{@m@}}\) iff \(k\ge{@m@}\), so \(k={@m@}\).

(c) \(1/r=1/{@r0@}\).

The overall structure is typical of BQP algorithms: a constant success probability per run amplified to \(1-2^{-m}\) with \(O(m)\) repetitions, at negligible cost compared with the exponential classical alternative. Verification is classical and cheap — multiply the factors back — so the algorithm is a Las Vegas procedure.
