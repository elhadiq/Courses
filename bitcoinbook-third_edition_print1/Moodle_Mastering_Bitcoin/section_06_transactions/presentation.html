Counts and lengths (varint)CompactSize

first byte < 0xfd -> that byte IS the value (0..252) first byte = 0xfd -> next 2 bytes, little-endian first byte = 0xfe -> next 4 bytes, little-endian first byte = 0xff -> next 8 bytes, little-endian

Example: fd 00 01 → read 2 LE bytes 00 01 = 0x0100 = 256.

3 / 7

Little-endianWarning

Bitcoin stores most integers least-significant byte first. So bytes 02 03 mean 0x0302 = 770, not 0x0203. Endianness is the classic beginner bug.
4 / 7

Weight and virtual sizeSize

SegWit discounts witness bytes.

weight = base_size × 3 + total_size
vsize = ceil(weight / 4)

Legacy 200 B: weight 800, vsize 200. SegWit base 100 / total 150: weight 450, vsize 113.
