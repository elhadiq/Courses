Course Overview

Mastering Bitcoin: Programming the Open Blockchain

A complete 14-section course based on the 3rd edition by Andreas M. Antonopoulos and David A. Harding. Each section pairs a reading page with three auto-graded coding exercises.

How this course is organized. Every chapter of the book becomes one section. Inside each section you will find a reading page — explaining the key ideas, terminology and learning objectives, with diagrams and figures — followed by three short, auto-graded coding exercises that turn those ideas into working Python. The exercises are self-contained: they use only the standard library (hashlib, json), with no Bitcoin node required.

How to work through the course

  1. Take the sections in order — each one builds on ideas from the last.
  2. Read the section page first, studying the diagrams and worked examples, then try the check-your-understanding questions.
  3. Finish each section by solving its three coding exercises, which put the concepts into practice.
