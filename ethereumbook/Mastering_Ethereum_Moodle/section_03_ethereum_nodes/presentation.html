What is a node?Idea

  • A node runs Ethereum client software and joins the P2P network.
  • A full node downloads and verifies the whole chain.
  • An archive node keeps all historical state forever.
Many independent, dispersed nodes = health, resilience, censorship resistance.

JSON-RPCAPI

Your program's gateway to a node: JSON commands over HTTP, port 8545, localhost by default.

{"jsonrpc":"2.0","method":"web3_clientVersion","params":[],"id":1} → {"jsonrpc":"2.0","id":1,"result":"Geth/1.14.3-stable/..."}

Four fields: jsonrpc, method, params, id.

5 / 7

Hex resultsSkill

Numbers come back hex-encoded. Convert to decimal to read them:

gas price = "0x1B1717FC7" 0x1B1717FC7 = 7,271,972,807 wei ≈ 7.27 gwei
In Python: int("0x1B1717FC7", 16). Libraries like web3.py do this for you.
6 / 7

Recap

A node runs two clients — execution (EVM) and consensus (proof of stake). Choose a full node, a public testnet, or a local simulation by the trust and cost you need. Talk to nodes via JSON-RPC on port 8545, and convert hex results to decimals to read them.
