Ethereum Basics

By the end of this lesson you will understand ether's units, the two kinds of Ethereum account, and how a first smart contract — a faucet — actually behaves.

What you will be able to do

  • Convert between ether and its smallest unit, wei, and name the denominations in between.
  • Explain what a wallet holds and why controlling your private keys matters.
  • Distinguish an externally owned account (EOA) from a contract account.
  • Trace what happens when someone withdraws from a faucet contract.

1. Ether and its units

Ethereum's currency is ether (ticker ETH, symbol Ξ). A common beginner's slip is to call the currency “Ethereum” — but Ethereum is the system, and ether is the currency that pays to use it.

Internally, Ethereum never stores fractional ether. Every value is an unsigned integer counted in the smallest unit, the wei. One ether is exactly one quintillion wei:

1 ether = 1 × 1018 wei = 1,000,000,000,000,000,000 wei

So when you send “1 ETH,” the transaction really encodes the integer 1,000,000,000,000,000,000. The named denominations in between honour pioneers of computing and cryptography:

The gwei (gigawei, 109 wei) is worth remembering: gas prices are almost always quoted in gwei.

2. Wallets and control

A wallet is a software application that manages your Ethereum account: it holds your keys and can create and broadcast transactions on your behalf. MetaMask, Rabby, and Phantom are common starter wallets that work as both browser extensions and mobile apps.

The key idea is control. In a decentralized system, each user can — and should — control their own private keys. As a first approximation, one private key equals one account. With that control comes responsibility: if you lose your private keys, no one can restore them, and the funds they secure are locked forever. Handing keys to a third-party custodian (like a centralized exchange) trades that responsibility for trust in someone else.

Golden rule. A wallet needs access to your private keys, so only install wallet software from sources you trust — and never share the keys themselves.

3. Two kinds of account

Ethereum has exactly two account types, and telling them apart is essential:

 Externally owned account (EOA)Contract account
Has a private key?YesNo
Has code?NoYes (a smart contract)
Can start a transaction?YesNo — only reacts to being called
Holds and sends ether?YesYes

The account you make in MetaMask is an EOA — it has a private key, and having the key means control. A contract account has no key; it is controlled entirely by the logic of its code. When a transaction is sent to a contract address, it causes that contract to run in the EVM, using the transaction's data to choose which function to call. Because a contract has no key, it can never initiate a transaction — it can only react.

4. A first contract: the faucet

A faucet is one of the simplest useful contracts: it hands out a little ether to any address that asks, and anyone can refill it. It is written in Solidity, Ethereum's dominant smart-contract language, and compiled to EVM bytecode.

The important behaviour to understand is the withdraw rule. A well-behaved faucet enforces two limits before it pays out. First, a request cannot exceed a fixed maximum per withdrawal (so one person cannot drain it). Second, it cannot pay more ether than it currently holds. If either check fails the withdrawal is rejected; otherwise the balance goes down by the requested amount. This is exactly the logic you will implement in the exercises.

Worked example

balance = 1000, request = 100, limit = 100 → pay out, new balance = 900
balance = 1000, request = 200, limit = 100 → rejected (over the per-withdrawal limit)
balance = 50, request = 100, limit = 100 → rejected (not enough funds)

Check your understanding

  1. How many wei are in 3 ether? (Answer: 3,000,000,000,000,000,000.)
  2. Which account type can initiate a transaction? (Answer: only an EOA.)
  3. Why can't a contract account start a transaction on its own? (Answer: it has no private key.)
  4. A faucet holds 50, its per-withdrawal limit is 100, and someone requests 60. What happens? (Answer: rejected — not enough funds.)
