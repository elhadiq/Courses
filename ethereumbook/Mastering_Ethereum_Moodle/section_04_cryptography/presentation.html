Private keysSecret

  • A private key is just a random number below 2256 (a 78-digit number).
  • Hold it → control the funds. Lose it → funds gone forever.
  • There are nearly as many keys as atoms in the visible universe.
Always use a cryptographically secure random source — never a plain rand().

Public keys & one-way functionsCore

K = k × G (secp256k1) k = private key G = generator point K = public key

Forward (private → public) is easy; reverse is infeasible — the discrete logarithm problem.

You can publish your public key to the world; no one can work back to your private key. This asymmetry underlies every signature.

6 / 8

ERC-55 checksumAnti-typo

Hash the lowercase address; capitalize a letter when its matching hash digit is ≥ 8. Digits never change.

address: 001d3f1ef827552ae1114027bd3ecf1f086ba0f9 hash : 23a69c1653e4ebbb619b0b2cb8a9bad49892a8b9... result : 001d3F1ef827552Ae1114027BD3ECF1f086bA0F9
Catches a mistyped address ~99.986% of the time, staying backward compatible.

Recap

A private key is a secret random number; the public key comes from it by one-way elliptic-curve multiplication. Cryptographic hashes are deterministic, irreversible and collision-resistant. An Ethereum address is the last 20 bytes of Keccak-256 of the public key, and ERC-55 hides a typo-catching checksum in the address's capitalization.
