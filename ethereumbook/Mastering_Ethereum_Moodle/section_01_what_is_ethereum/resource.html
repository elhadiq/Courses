What Is Ethereum?

By the end of this lesson you will be able to explain what the “world computer” really is, how it differs from Bitcoin, and why every program it runs must pay for the resources it uses.

What you will be able to do

  • Describe Ethereum as a decentralized state machine that runs programs called smart contracts.
  • List the components that every open blockchain shares and name the ones specific to Ethereum.
  • Explain what “Turing complete” means and why it forces Ethereum to meter computation with gas.
  • Place the four development stages (Frontier, Homestead, Metropolis, Serenity) on a timeline.

1. A computer that no one owns

Imagine a single computer that everybody in the world shares. You cannot unplug it, no company runs it, and every instruction it executes is checked by thousands of machines at once. If you send it a program, that program runs exactly the same way for everyone, and the result is recorded permanently so that nobody can later deny it happened. That shared machine is what people mean when they call Ethereum the “world computer.”

Said more precisely, Ethereum is a deterministic state machine. A state machine is just something that has a current situation (its “state”) and a set of rules for moving from one situation to the next. Deterministic means the same starting state plus the same input always produces the same next state — there is no randomness and no ambiguity. Ethereum keeps one single, globally shared state, and a virtual machine applies changes to it. The programs that request those changes are called smart contracts, and a cryptocurrency called ether is used to pay for running them.

2. Ethereum compared to Bitcoin

Many people meet Ethereum after Bitcoin, so it helps to line them up. Both are open blockchains: both use a peer-to-peer network, a fault-tolerant way of agreeing on what happened, cryptographic signatures and hashes, and a digital currency. The difference is purpose. Bitcoin was built to be digital money, and its scripting language is deliberately tiny — it can only answer simple true/false questions about whether a payment is allowed.

Ethereum was built to be a general-purpose, programmable blockchain. Its language is Turing complete, which (as we will see in section 4 below) means it can run a program of any complexity. Ether is not primarily meant to be spent like cash; it is a utility currency that pays for using the world computer. In September 2022, an upgrade called The Merge switched Ethereum from proof of work (miners racing with electricity) to proof of stake (validators locking up ether as a security deposit), cutting its energy use by more than 99%.

In one line

Bitcoin tracks who owns which coins. Ethereum tracks the state of any program you can write — money is just one thing you can build with it.

3. The parts of a blockchain

Every open, public blockchain is assembled from the same building blocks. Understanding them once means you understand every chain you will ever meet:

ComponentWhat it does
P2P networkConnects participants and gossips transactions and blocks around the world. Ethereum uses port 30303.
TransactionsSigned messages that request a change of state (a sender, a recipient, a value, and a data payload).
Consensus rulesThe shared rulebook for what counts as a valid transaction and a valid new state.
State machineProcesses transactions. In Ethereum this is the EVM (Ethereum Virtual Machine).
Chain of blocksA cryptographically linked journal of every accepted state change.
Consensus algorithmForces independent participants to agree, decentralizing control. Ethereum now uses proof of stake.
ClientsSoftware that implements all of the above (e.g., Geth, Nethermind for execution; Prysm, Lighthouse for consensus).

Blockchains are not all the same. Two dials help us describe any of them. The first is permissionless vs permissioned: can anyone join and take part, or only approved participants? The second is public vs private: is the data open to everyone, or limited to a chosen group? Bitcoin and Ethereum are public permissionless chains — anyone can read, write, and help run them.

4. Turing completeness and the gas idea

In 1936 the mathematician Alan Turing described an abstract machine that manipulates symbols on an endless tape. A system is called Turing complete if it can imitate that machine — in plain words, if it can compute anything that is computable. Ethereum can load a stored program and run it while reading and writing memory, so it is Turing complete. That is its superpower: any program of any complexity can run on it.

But that same power is dangerous. Turing also proved the halting problem: in general you cannot tell in advance whether a program will ever stop. On a shared world computer, a contract that loops forever would freeze the machine for everyone — and unlike a frozen printer you cannot just switch a blockchain off and on again. So how do you allow unlimited computation without letting one program hog the world's resources?

Ethereum's answer is gas. As the EVM runs a contract, it charges a fixed amount of gas for every single instruction. A transaction must carry an upper limit of gas it is willing to spend. If execution burns through that limit, the EVM stops the program immediately. Gas is bought with ether at the time of the transaction, and any gas you don't use is refunded. This is exactly what the exercises for this section model.

Worked example

gas limit = 100 units
instructions cost = [10, 20, 30]
after running all three: 100 − 60 = 40 gas left

gas limit = 50, instructions = [30, 30]
first costs 30 → 20 left; second needs 30 → out of gas (program halts)

5. Stages of development

Ethereum was planned in four stages, each introducing major changes, sometimes through backward-incompatible upgrades called hard forks:

StageLaunchedMilestone
FrontierJul 30, 2015 (block 0)The genesis block; mining and the first DApps.
HomesteadMar 14, 2016 (block 1,150,000)Safer, more stable protocol.
MetropolisOct 16, 2017 (block 4,370,000)Byzantium, Constantinople, Istanbul; cheaper gas, more security.
SerenitySep 15, 2022“Ethereum 2.0”: proof of stake, in substages (The Merge, Surge, Scourge, Verge, Purge, Splurge).

From this general-purpose foundation grew decentralized applications (DApps) — at minimum a smart contract plus a web interface — and the broader vision of Web3, a version of the web built on decentralized protocols rather than centrally owned services.

Check your understanding

  1. What single word captures the difference in purpose between Bitcoin and Ethereum? (Answer: programmability — Ethereum is general-purpose.)
  2. Why can't Ethereum simply predict whether a contract will finish running? (Answer: the halting problem is unsolvable.)
  3. A transaction has a gas limit of 100 and its instructions cost 10 + 20 + 30. How much gas is left? (Answer: 40.)
  4. Which stage introduced proof of stake? (Answer: Serenity, via The Merge.)
