The nonceTwo jobs

  • Ordering: nonce 4 waits for nonce 3 — the one you sent first wins.
  • Duplicate protection: each tx is unique, so no one can replay it.
It is a per-sender count of confirmed transactions — vital for an account-based chain.

fee = gas_used × (base_fee + priority_fee) base fee → burned priority → validator (tip) EOA transfer = 21,000 gas (fixed)

RecipientCareful

  • The to field is a 20-byte address (EOA or contract).
  • Ethereum does not validate it.
Send to a mistyped address and the ether is usually burned forever — validate with ERC-55 in the UI.

Recap

A transaction is a signed state-change request tagged by a type byte. The nonce orders transactions and blocks replays. Fees under EIP-1559 are gas_used x (base_fee + priority_fee), with a plain transfer fixed at 21,000 gas. The value and data fields carry ether and, for contracts, the function to call.
