Lab: the full pipeline

Goal A single workflow that lints, tests against real Redis, builds a SHA-tagged image, pushes it to GHCR, and blocks merges when anything fails.

Step 1 — the complete workflow

Create .github/workflows/ci.yml:

name: CI

on:
  push:
    branches: [main]
  pull_request:
  workflow_dispatch:

env:
  IMAGE: ghcr.io/${{ github.repository }}

jobs:

  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12", cache: pip }
      - run: pip install ruff
      - run: ruff check .
      - run: ruff format --check .

  test:
    runs-on: ubuntu-latest
    services:
      redis:
        image: redis:7-alpine
        ports: ["6379:6379"]
        options: >-
          --health-cmd "redis-cli ping"
          --health-interval 5s --health-timeout 3s --health-retries 5
    env:
      REDIS_URL: redis://localhost:6379/0
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12", cache: pip }
      - run: pip install -r requirements.txt
      - run: python -m pytest -q --junitxml=report.xml
      - if: always()
        uses: actions/upload-artifact@v4
        with:
          name: test-report
          path: report.xml

  build:
    needs: [quality, test]
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    permissions: { contents: read, packages: write }
    steps:
      - uses: actions/checkout@v4
      - uses: docker/setup-buildx-action@v3
      - uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - id: meta
        uses: docker/metadata-action@v5
        with:
          images: ${{ env.IMAGE }}
          tags: |
            type=sha,format=long
            type=raw,value=latest
      - uses: docker/build-push-action@v6
        with:
          context: .
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          cache-from: type=gha
          cache-to: type=gha,mode=max

  smoke:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run the published image and probe it
        run: |
          docker network create smokenet
          docker run -d --name redis --network smokenet redis:7-alpine
          docker run -d --name api --network smokenet -p 8000:8000 \
            -e REDIS_URL=redis://redis:6379/0 \
            ghcr.io/${{ github.repository }}:sha-${{ github.sha }}
          chmod +x healthcheck.sh
          ./healthcheck.sh http://localhost:8000/health 15
      - if: failure()
        run: docker logs api
What the smoke job is really testing Unit tests prove your code is correct. The smoke job proves the artefact is correct — that the image you are about to deploy actually boots, finds its dependency and serves traffic. Those fail for completely different reasons, which is why both jobs exist. Note it reuses healthcheck.sh from Module 1, and that if: failure() dumps logs so a red build is diagnosable without re-running it.

Step 2 — add ruff config so lint is not noise

cat > ruff.toml <<'EOF'
line-length = 100
target-version = "py312"

[lint]
select = ["E", "F", "I", "UP", "B"]
EOF

pip install ruff
ruff check . && ruff format .

Step 3 — push and watch it fail, then pass

git switch -c ci/pipeline
git add .github ruff.toml
git commit -m "ci: add lint, test, build and smoke pipeline"
git push -u origin ci/pipeline

Open a Pull Request. Watch quality and test run in parallel; build is skipped because the ref is not main. Fix whatever ruff complains about, push again, and watch it go green.

Step 4 — make the checks binding

Settings → Branches → main → Edit. Enable Require status checks to pass before merging and select quality and test. Now merging red code is not possible, rather than merely discouraged.

Step 5 — merge and verify the artefact

# after merging the PR on GitHub:
git switch main && git pull

SHA=$(git rev-parse HEAD)
docker pull ghcr.io/<you>/urlshort:sha-$SHA
docker run --rm ghcr.io/<you>/urlshort:sha-$SHA python -c "import app.main; print('image ok')"

Step 6 — prove the gate works

git switch -c break/tests
sed -i 's/assert len(code) == 7/assert len(code) == 99/' tests/test_api.py
git commit -am "test: deliberately break a test"
git push -u origin break/tests

Open a PR. The merge button is now blocked. Revert the change, push, and watch it unblock. That transition is the entire point of the module.
