5.4 Terraform: the core loop

terraform init      # download providers, set up the backend. Run once per project/change.
terraform fmt       # canonical formatting — put this in CI
terraform validate  # syntax and internal consistency
terraform plan      # show me what you WOULD change. Read this. Every time.
terraform apply     # make it so
terraform destroy   # tear it all down
plan is the safety mechanism, not a formality Read the plan symbols before typing yes: + create, ~ update in place, - destroy, -/+ destroy and recreate. That last one is where production databases die. When you see -/+ on something stateful, stop and find out which attribute forced it.
