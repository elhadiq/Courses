5.2 Declarative vs imperative

ImperativeDeclarative
You writeThe steps to takeThe end state you want
Exampleapt install nginx && systemctl start nginxnginx is installed and running
Run twiceMay error or duplicate workSecond run does nothing — already true
ToolsShell scriptsTerraform, Ansible modules, Kubernetes manifests

The declarative model gives you idempotency: applying the same configuration any number of times converges on the same result. That property is what makes automation safe to re-run, which is what makes it usable at all — an automation you are afraid to run twice is not automation.
