5.7 Modules and environments

A module is just a directory of .tf files you can call with different inputs. It is how you avoid copy-pasting staging into production and letting them drift apart.

terraform/
├── modules/
│   └── app/
│       ├── main.tf
│       ├── variables.tf
│       └── outputs.tf
└── envs/
    ├── dev/main.tf
    └── prod/main.tf
# envs/dev/main.tf
module "app" {
  source = "../../modules/app"

  project   = "urlshort-dev"
  api_port  = 8000
  api_image = "urlshort:0.1.0"
  replicas  = 1
}

Same code, different inputs — so staging is genuinely a smaller copy of production rather than a different system that resembles it.
