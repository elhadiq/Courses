7.11 Logs that are actually searchable

Structured logs — one JSON object per line — are greppable and queryable:

import json, logging, sys

class JsonFormatter(logging.Formatter):
    def format(self, record):
        return json.dumps({
            "ts": self.formatTime(record),
            "level": record.levelname,
            "msg": record.getMessage(),
            "logger": record.name,
            **getattr(record, "extra_fields", {}),
        })

handler = logging.StreamHandler(sys.stdout)   # stdout, always
handler.setFormatter(JsonFormatter())
logging.basicConfig(handlers=[handler], level=logging.INFO)

Three rules that matter more than the format:

  1. Log to stdout. The container runtime collects it. A log file inside a container is lost when the pod dies — exactly when you need it.
  2. Include a request ID and propagate it across services, so one user's journey is one query.
  3. Never log secrets or personal data. Logs are widely readable and retained for a long time; this is a compliance problem as much as a security one.
