Capstone project

Build a new service end to end, from an empty directory, using nothing but the docs. Pick something small with a datastore — a paste bin, a feature-flag API, a webhook receiver.

Deliverables

  • A Git repository with protected main and short-lived feature branches.
  • A multi-stage Dockerfile: non-root, correct layer ordering, under 150 MB.
  • A Compose file for local development, with a healthcheck-gated dependency.
  • A GitHub Actions pipeline: lint → test (against a real service container) → build → push a SHA-tagged image to GHCR → smoke test the published image.
  • Terraform describing the environment, with variables, outputs and a clean plan.
  • An idempotent Ansible playbook (second run: changed=0).
  • Kubernetes manifests: probes that distinguish liveness from readiness, resource requests and limits, ConfigMap and Secret, maxUnavailable: 0.
  • Prometheus instrumentation for all four golden signals, a Grafana dashboard committed as JSON, and at least two symptom-based alerts.
  • A README.md that a stranger can follow from clone to running system.

The demonstration

Record or perform these four things live. They are what an interviewer would ask for:

  1. Push a commit that breaks a test; show the merge being blocked.
  2. Perform a rolling update under continuous traffic with zero non-200 responses.
  3. Deploy a broken image; show that users are unaffected; roll back.
  4. Kill the datastore; show the alert firing, pods leaving rotation without restarting, and automatic recovery when it returns.

Where to go next

  • GitOps — Argo CD or Flux: the cluster pulls its desired state from Git instead of CI pushing to it.
  • Helm — package your manifests so environments differ by values, not by copies.
  • Distributed tracing — OpenTelemetry and Jaeger, once you have more than one service.
  • Policy and supply chain — OPA/Kyverno for admission control, cosign for image signing, SBOMs.
  • Cloud — take this exact stack to EKS or GKE; the Terraform providers change, the concepts do not.
