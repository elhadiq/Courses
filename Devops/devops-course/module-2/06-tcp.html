2.6 TCP vs UDP

TCPUDP
ConnectionYes — three-way handshake firstNo — just send
DeliveryGuaranteed, retransmits lossesBest effort, no retry
OrderingReassembled in orderMay arrive out of order
OverheadHigher (ACKs, state, congestion control)Minimal
Used byHTTP, HTTPS, SSH, Redis, Postgres, SMTPDNS (usually), NTP, VoIP, video, QUIC

TCP opens a connection with a three-way handshake — and knowing its shape makes tcpdump output readable:

client → server   SYN            # "can we talk?"
server → client   SYN, ACK       # "yes, can we?"
client → server   ACK            # "yes" — connection established

If you see SYN repeated with no reply, packets are being dropped — a firewall. If you see SYN answered with RST (reset), the host is reachable but refusing — nothing is listening on that port. Same two diagnoses as section 2.2, now visible on the wire.
