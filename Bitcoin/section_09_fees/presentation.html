Transaction Fees

Mastering Bitcoin · Section 9 — bidding for scarce block space

1 / 7

Fees exist because space is scarceWhy

Each block holds limited data, so transactions compete. A transaction offers a fee (inputs minus outputs) and miners prefer the most value per unit of space.

As the subsidy shrinks each halving, fees become miners' main reward.
2 / 7

Absolute fee vs. fee rateTwo numbers

  • Absolute fee — total satoshis (inputs − outputs).
  • Fee rate — satoshis per virtual byte (sat/vB).
fee_rate = fee / vsize   and   fee = fee_rate × vsize
3 / 7

Choosing the right rateEstimation

Pay too little and you wait; too much and you overpay. Wallets estimate the rate from recent blocks (estimatesmartfee): higher for 'next block', lower for 'within a day'.

4 / 7

RBF and CPFPUn-sticking

RBF — re-broadcast the same tx with a higher fee. Valid only if it pays a higher absolute fee and a higher rate.

CPFP — spend a stuck output with a high-fee child, pulling both in.

Sender → use RBF. Receiver → use CPFP.
