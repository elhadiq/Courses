Mastering Bitcoin · Section 10 — thousands of equal peers gossiping

1 / 7

A network of equalsP2P

Bitcoin is peer-to-peer: no central server. Each node connects to a few others and gossips new transactions and blocks onward. Nodes join or leave freely; there is nothing to shut down.

2 / 7

Finding peers and the handshakeDiscovery

A new node bootstraps via DNS seeds, then asks peers for more addresses. Two peers handshake with version / verack.

3 / 7

Full nodes vs. lightweight (SPV)Clients

Full nodes verify everything. SPV clients (phones) download only 80-byte headers and ask peers for merkle proofs.

4 / 7

Bloom filtersPrivacy

A bloom filter is a bit array that tests membership probabilistically. Set bits for your addresses, share the fuzzy filter.

All bits set → maybe present. Any bit 0 → definitely not.
5 / 7

Coding exercisesPractice

  1. bloom_insert(m, positions) — build a bit array.
  2. bloom_test(bits, positions) — membership check.
  3. new_inventory(known, inv) — fetch only unknown items.
