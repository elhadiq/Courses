Rules need software that runs themConcept

A rulebook on paper does nothing. Someone must actually check every transaction: valid signature? already spent? valid block?

  • Bitcoin Core is the descendant of Satoshi's original 2009 client, free and open source.
  • It is the reference implementation: its behaviour defines the rules in practice.
If another program disagrees with Bitcoin Core about a block's validity, that program is considered broken.
2 / 9

What is a full node?Full node

Running Bitcoin Core makes your computer a full node — it trusts no one and verifies everything itself.

  • Downloads and checks the entire blockchain against the rules.
  • Keeps the UTXO set — all current spendable coins.
  • Relays transactions and blocks; optionally runs a wallet.
Why run one? You rely on no bank or company — your own machine confirms what's true. Cost: disk space and sync time.

Talking to a node: JSON-RPCAPI

  • API — a defined set of commands.
  • RPC — call a function remotely, get a result.
  • JSON — the text format of request and reply.
Always check error before trusting result.
request: {"method":"getblockcount", "params":[], "id":1} reply: {"result":840000, "error":null, "id":1}
5 / 9

bitcoin-cli: the front doorTooling

The bitcoin-cli tool builds the JSON request for you:

$ bitcoin-cli getblockcount 840000 $ bitcoin-cli getblockhash 0 000000000019d6689c085ae165831e934ff763ae46a2a6c172b3f1b60a8ce26f

Common calls: getblockcount, getblockhash, getrawtransaction, getbalance, listunspent.

Reading coins: listunspentBalances

Your balance is the sum of your UTXOs. listunspent returns each one with an amount and a confirmations count.

A common rule counts only coins with ≥ 6 confirmations as fully spendable; shallower ones are "pending".
confirmed_balance = sum(amount_sat for UTXO if confirmations >= min_conf)

Coding exercisesPractice

Using Python's json module:

  1. rpc_request(method, params) — build a JSON-RPC request string.
  2. rpc_result(response) — parse a reply; return the result or None on error.
  3. confirmed_balance(utxos) — sum UTXOs with enough confirmations.
