1.1 What a learning problem is

Supervised learning starts from an unknown joint probability distribution P(x, y) over an input space X and an output space Y. We never see P; we only observe a finite sample of n pairs drawn independently from it, called the training set.

\[D = \{(x_1, y_1), (x_2, y_2), \ldots , (xₙ, yₙ)\} drawn i.i.d. from P(x, y)\]

The goal is to choose a function f from a hypothesis class H that makes small errors on future pairs from the same distribution. Error is quantified by a loss function L(y, f(x)), and the quantity we truly care about is the expected risk [2]:

\[R(f) = \mathbf{E}_{(x,y)\sim P} [ L(y, f(x)) ]\]

Because P is unknown, this expectation cannot be computed. We replace it by its sample average, the empirical risk:

\[\hat{R}(f) = (1/n) \sum_{i=1..n} L(y_{i}, f(x_{i}))\]
Definition — Empirical Risk Minimisation (ERM)
The ERM principle selects \(\hat{f} = \operatorname{argmin}_{f\in H} \hat{R}(f)\). Vapnik and Chervonenkis [1] proved that ERM is consistent — that R(\(\hat{f}\)) converges to the best achievable risk in H — if and only if the empirical risk converges uniformly over H, a condition controlled by the VC dimension of the class.
No free lunch
Wolpert [11] showed that, averaged over all possible target functions, every learning algorithm has the same expected off-training-set error. There is no universally best learner: performance always comes from assumptions (the inductive bias) that happen to match the problem.

1.2 Linear regression and the least-squares estimator

The simplest non-trivial hypothesis class is the set of affine functions. With the squared loss \(L(y, f(x)) = (y - f(x))^2\), ERM becomes the method of least squares, published by Legendre in 1805 [3] and justified probabilistically by Gauss in 1809 [4].

\[f_{\theta}(x) = \theta_0 + \theta_1x_1 + \ldots + \theta_{d}x_{d} = \theta^{T}\tilde{x}\]

Stacking the n augmented inputs as rows of a design matrix X (size \(n\times (d+1)\)) and the targets in a vector y, the objective is:

\[J(\theta ) = \| y - X\theta \|^2_2\]
Theorem — Normal equations
J is convex and differentiable; setting \(\nabla J(\theta ) = -2X^{T}(y - X\theta ) = 0\) gives \(X^{T}X\theta = X^{T}y\). If X has full column rank, \(X^{T}X\) is invertible and the unique minimiser is \(\hat{\theta} = (X^{T}X)^{-1}X^{T}y\). Geometrically, \(X\hat{\theta}\) is the orthogonal projection of y onto the column space of X, so the residual vector is orthogonal to every predictor [10].

In one dimension the closed form reduces to the familiar covariance-over-variance ratio, which the interactive figure below recomputes as you drag the points:

\[\theta_1 = \sum (x_{i}-\bar{x})(y_{i}-\bar{y}) / \sum (x_{i}-\bar{x})^2 \theta_0 = \bar{y} - \theta_1\bar{x}\]

1.3 Gradient descent

Solving the normal equations costs O(\(nd^2 + d^3\)), which is prohibitive when d is large. Iterative first-order methods scale far better, and they generalise to models with no closed-form solution — which is essentially every model from Section 2 onwards.

\[\theta^{(t+1)} = \theta^{(t)} - \eta \nabla J(\theta^{(t)}) with \nabla J(\theta ) = -(2/n) X^{T}(y - X\theta )\]

For a convex, L-smooth objective, gradient descent with step size \(\eta \le 1/L\) converges, and the error after t steps decreases as O(1/t). If in addition J is \(\mu -\)strongly convex, convergence is linear at rate (1 \(- \mu /L\)). For least squares, L and \(\mu\) are the largest and smallest eigenvalues of (2/n)\(X^{T}X\), so the condition number of the design matrix directly governs the speed.

Stochastic gradient descent replaces the full-sample gradient by the gradient of a single example (or a mini-batch). Robbins and Monro [9] proved convergence under the step-size conditions \(\sum \eta_{t} = \infty\) and \(\sum \eta_{t}^2 \lt \infty\) — the steps must be large enough to travel anywhere, yet decay fast enough for the noise to average out.

import numpy as np

def fit_gd(X, y, eta=0.05, n_iter=500):
    """Batch gradient descent for linear regression. X already has a bias column."""
    n, d = X.shape
    theta = np.zeros(d)
    history = []
    for _ in range(n_iter):
        residual = y - X @ theta
        grad = -(2.0 / n) * (X.T @ residual)
        theta = theta - eta * grad
        history.append(float(residual @ residual) / n)
    return theta, history

1.4 Overfitting and the bias–variance decomposition

Minimising empirical risk over a rich class is dangerous: a polynomial of degree n−1 interpolates n points exactly, giving zero training error and, usually, appalling test error. The classical account of this is the bias–variance decomposition [5].

Theorem — Bias–variance decomposition
Let y = g(x) + \(\epsilon\) with E[\(\epsilon ] = 0\) and Var(\(\epsilon ) = \sigma^2\), and let \(\hat{f}_{D}\) be the model fitted on a random training set D. Then for any fixed x, the expected squared error decomposes as:
\[\mathbf{E}_{D,\epsilon}[(y - \hat{f}_{D}(x))^2] = (g(x) - \mathbf{E}_{D}[\hat{f}_{D}(x)])^2 + Var_{D}(\hat{f}_{D}(x)) + \sigma^2\]

The three terms are the squared bias (systematic error from a class too poor to represent g), the variance (sensitivity to which particular training set was drawn), and the irreducible noise \(\sigma^2\), which no model can beat.

Increasing model complexity lowers bias and raises variance. The classical U-shaped test error curve is the sum of the two. This picture is not the whole story for very large models: Belkin et al. [12] documented a double descent regime in which test error falls again once the model passes the interpolation threshold, which is why heavily over-parameterised neural networks (Section 8) can still generalise.

1.5 Regularisation

Rather than restricting the class by hand, we penalise complexity inside the objective. Two penalties dominate practice:

\[\mathbf{Ridge} [6]: J(\theta ) = \| y - X\theta \|^2_2 + \lambda \| \theta \|^2_2\]
\[\mathbf{Lasso} [7]: J(\theta ) = \| y - X\theta \|^2_2 + \lambda \| \theta \|_1\]

Ridge has the closed form \(\hat{\theta} = (X^{T}X + \lambda I)^{-1}X^{T}y\), which is well defined even when \(X^{T}X\) is singular — that was Hoerl and Kennard's original motivation for collinear designs. It shrinks coefficients smoothly toward zero but never exactly to zero.

The lasso penalty is not differentiable at the origin, and its level sets are diamonds whose corners lie on the axes. The solution therefore tends to land on a corner, setting coefficients exactly to zero: the lasso performs variable selection as a side effect of fitting.

1.6 Estimating generalisation honestly

The training error is a biased estimate of the risk. Stone [8] formalised K-fold cross-validation: split the data into K folds, fit on K−1 and evaluate on the held-out fold, then average the K scores. K = 5 or 10 is the usual compromise — small K gives a pessimistic, high-bias estimate; K = n (leave-one-out) is nearly unbiased but has high variance and costs n fits.

The most common leak in practice
Any preprocessing that learns from data — standardisation, feature selection, imputation, PCA — must be fitted inside each fold, on the training portion only. Standardising the whole dataset before splitting lets test information into the model and produces optimistic scores that vanish in production.
def k_fold_indices(n, k, seed=0):
    """Yield (train_idx, test_idx) for K-fold cross-validation."""
    import random
    idx = list(range(n))
    random.Random(seed).shuffle(idx)
    folds = [idx[i::k] for i in range(k)]
    for i in range(k):
        test = folds[i]
        train = [j for f in range(k) if f != i for j in folds[f]]
        yield train, test

Summary

  • Learning = minimising an unobservable expected risk through its empirical proxy; consistency of ERM is governed by the capacity of the hypothesis class [1].
  • Least squares has the closed-form solution \(\hat{\theta} = (X^{T}X)^{-1}X^{T}y\) and a clean geometric reading as orthogonal projection.
  • Gradient descent trades exactness for scalability; its speed is set by the condition number of \(X^{T}X\).
  • Test error = \(bias^2 +\) variance + noise [5]; complexity moves the first two in opposite directions.
  • Ridge stabilises, lasso selects; both are ERM with a penalty and both need \(\lambda\) chosen by cross-validation [8].
